# GenaMath

A sleek, professional multi-calculator app with:
- **Savings Calculator** - Calculate savings projections based on salary and contribution rate
- **Bonus Calculator** - Quickly calculate bonus amounts from a base figure
- **Currency Converter** - Real-time currency conversion between major currencies

## Features

✨ **Clean, Classy Design**
- Elegant dark theme with gold accents
- Professional typography and spacing
- Smooth, intuitive navigation

🧮 **Three Powerful Calculators**
- Input your salary and savings rate to project your savings
- Calculate bonuses from base amounts
- Convert currencies instantly

📱 **Mobile-First**
- Responsive design for all screen sizes
- Easy-to-use input fields
- Clear result displays

## How to Use

1. Open the app in MIT App Inventor or on your Android device
2. Select a calculator from the main menu
3. Enter your values
4. Get instant results
